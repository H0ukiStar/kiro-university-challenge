# リポジトリ構成

本リポジトリは複数のツールを収容する親階層を持つ。ツールごとにディレクトリを分けて配置する。

```
kiro-university-challenge/
├── aws-eip-cleaner/          # ツール本体（言語ごとの標準レイアウトに従う）
└── docs/                     # ドキュメント類
```

- 各ツールはリポジトリ直下に独立したディレクトリとして配置すること。
- 各ツール内部のレイアウトは、使用する言語・エコシステムの標準に従うこと（Python の場合は `python.md` を参照）。
- ドキュメント類は `docs/` 配下に配置すること。
