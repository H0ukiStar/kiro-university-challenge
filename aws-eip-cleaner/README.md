# aws-eip-cleaner

AWS アカウント上の未利用 Elastic IP（EIP）を検出して解放する CLI ツール。

いずれのリソースにも関連付けられていない（Association ID を持たない）割り当て済み EIP を
「未利用 EIP」とみなして検出する。コマンドラインオプションで調査対象リージョンや認証
プロファイルを指定でき、複数リージョンを最大 16 並列で調査する。検出した EIP を一覧表示した
うえで、対話的な確認・ドライラン・確認スキップによる一括解放から実行モードを選んで整理できる。

## クイックスタート

環境・パッケージ管理には [uv](https://docs.astral.sh/uv/) を使用する。

```sh
# 依存をインストール
uv sync
```

最小の実行例として、アクセス可能な全リージョンをドライラン（解放せず一覧のみ表示）で調査する。

```sh
# 全リージョンを調査し、未利用 EIP の一覧だけを表示する（解放は行わない）
uv run python -m aws_eip_cleaner --dry-run
```

AWS の認証情報は boto3 の標準的な解決チェーン（環境変数、共有認証情報ファイル、
インスタンスプロファイル等）に従う。特定のプロファイルを使う場合は `--profile` を指定する。

```sh
# プロファイルと調査対象リージョンを指定してドライラン
uv run python -m aws_eip_cleaner --profile my-profile --region us-east-1 --dry-run
```

## 主要オプション

| オプション | 引数 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `--region` | リージョン名 | （全リージョン） | 調査対象のリージョンを指定する。繰り返し指定可能（1〜50 回、重複は 1 件に統合）。無指定時はアクセス可能な全リージョンを対象とする。 |
| `--profile` | プロファイル名 | 標準の解決チェーン | 使用する AWS 認証プロファイル名。 |
| `--dry-run` | なし | 無効 | 解放を行わず、対象となる EIP の一覧と総件数を表示するのみとする。 |
| `--yes` | なし | 無効 | 対話確認を省略し、対象の EIP を一括で解放する。`--dry-run` とは併用できない。 |

`--dry-run` と `--yes` のいずれも指定しない場合は、検出した EIP を 1 件ずつ確認する対話モードで
動作する（承認は `y`、拒否は `n`）。詳細な使用例やオプションの説明は
[利用者向けドキュメント](docs/usage.md) を参照。

解放（release）は取り消せない操作である。実行前に `--dry-run` で対象を確認することを推奨する。
